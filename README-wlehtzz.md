# 🌐 Portfólio — Letícia Fantucci Medina

Site pessoal de portfólio, reunindo os projetos e habilidades de Letícia
Fantucci Medina, estudante de Análise e Desenvolvimento de Sistemas que une
código e imagem.

## Sobre o site

- **Header** — apresentação: "Estudante de ADS construindo uma ponte entre
  código e imagem — telas, paletas e interfaces", com links para GitHub,
  LinkedIn e email.
- **Projetos** — destaque para 4 trabalhos:
  1. [30 Poses](https://github.com/wlehtz/30poses) — ensaio sobre fotografia analógica (HTML/CSS/JS)
  2. [Filtro Analógico](https://github.com/wlehtz/filtro-analogico) — filtro de imagem estilo fotografia analógica (Python + Pillow)
  3. Paleta de Cores — extração das cores dominantes de uma imagem (Python)
  4. [Organizador de Guarda-Roupa](https://github.com/wlehtz/guarda-roupa) — catálogo de roupas (Python)
- **Sobre** — trajetória unindo experiência em atendimento e organização com
  formação em tecnologia.
- **Habilidades** — código (HTML, CSS, JavaScript, Python, Git), visual (Canva,
  Photoshop, Illustrator, CorelDRAW, Audaces Moldes), atendimento/organização
  e idiomas (português nativo, inglês intermediário).
- **Footer** — contatos (email, telefone, GitHub, LinkedIn) e localização em
  Guarulhos, SP.

Não há build nem dependências — é só abrir o `index.html` no navegador.

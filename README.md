# Portfólio — Letícia Fantucci Medina

Site pessoal de portfólio, publicado em [wlehtz.com.br](https://www.wlehtz.com.br).
Reúne meus projetos de front-end e de imagem, com uma identidade visual
inspirada em rolo de filme 35mm.

## O que tem no site

- **Topo** — nome, área em que estou me desenvolvendo (front-end) e links para
  GitHub, LinkedIn, e-mail e currículo em PDF.
- **Projetos** — três trabalhos, cada um com imagem, contexto e links:
  1. [30 Poses](https://github.com/wlehtz/30poses) — ensaio visual sobre fotografia analógica (HTML, CSS e JavaScript)
  2. [Filtro Analógico](https://github.com/wlehtz/filtro-analogico) — filtro de foto estilo câmera de filme dos anos 90 (Python + Pillow), com demo no navegador
  3. [Paleta de Cores](https://github.com/wlehtz/paleta-de-cores) — extração das cores dominantes de uma foto (Python + Pillow), com demo no navegador
- **Sobre** — formação em ADS, experiência em atendimento na área da saúde e
  habilidades de código, design e idiomas.
- **Contato** — e-mail, telefone, GitHub, LinkedIn e currículo.

As páginas `demo-filtro.html` e `demo-paleta.html` reproduzem os scripts em
JavaScript para rodar direto no navegador. A imagem enviada não sai do
computador de quem usa.

## Como rodar localmente

Não há build nem dependências: basta abrir o `index.html` no navegador.

## Tecnologias

HTML5, CSS3 e JavaScript, sem frameworks.
